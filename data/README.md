# Datos de práctica

La imagen utilizada en la demostración es `DSCN0010.jpg`, tomada del repositorio público `ianare/exif-samples`, ruta `jpg/gps/DSCN0010.jpg`.

No se versiona directamente en este repositorio. Para descargarla ejecuta:

```bash
python src/00_descargar_muestra.py
```

La muestra conserva metadatos EXIF útiles para fines educativos, incluidos datos del dispositivo, fecha/hora e información GPS.
